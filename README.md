# سیستم جامع غلط‌یاب و نرمال‌ساز چندزبانه

این پروژه یک وب‌سرویس پیشرفته مبتنی بر **FastAPI** و **Vercel** است که متن شما را در چهار زبان **فارسی، انگلیسی، عربی و ترکی استانبولی** با بالاترین دقت پردازش و اصلاح می‌کند.

## 🚀 ویژگی‌های کلیدی
- **تشخیص هوشمند زبان (Script Analysis)**: برخلاف روش‌های سنتی، این سیستم زبان هر خط را بر اساس کاراکترهای یونیکد تشخیص می‌دهد. این یعنی متون ترکیبی (مثلاً یک پاراگراف فارسی و یک پاراگراف انگلیسی) بدون خطا پردازش می‌شوند.
- **غلط‌یابی تخصصی**:
  - **فارسی**: استفاده از `hazm` برای اصلاح نیم‌فاصله و الگوریتم اختصاصی برای حذف حروف تکراری.
  - **عربی**: استفاده از `pyarabic` برای اصلاح همزه و حذف اعراب، و `pyspellchecker` برای اصلاح کلمات.
  - **انگلیسی**: غلط‌یابی با `pyspellchecker` با حفظ حروف بزرگ و علائم نگارشی.
- **الگوریتم ضدباگ حروف تکراری**: کلماتی مثل `سسسلام` را به `سلام` و `Helllo` را به `Hello` تبدیل می‌کند، بدون اینکه به کلمات صحیحی مثل `ممکن` آسیب بزند.
- **طراحی واکنش‌گرا (Responsive)**: رابط کاربری مدرن با دکمه‌های کپی و پاک کردن، مناسب برای موبایل و دسکتاپ.

## 🛠️ تکنولوژی‌ها
- **Backend**: Python 3.12, FastAPI, Mangum
- **NLP Libraries**: PySpellChecker, PyArabic, Hazm
- **Frontend**: HTML5, CSS3, Vanilla JS
- **Hosting**: Vercel Serverless

## 📦 نحوه‌ی استقرار (Deploy)
1. کدها را در یک مخزن GitHub قرار دهید.
2. در داشبورد Vercel، مخزن را Import کنید.
3. تنظیمات را روی حالت پیش‌فرض رها کرده و Deploy بزنید. (فایل `vercel.json` به صورت خودکار مسیرها را مدیریت می‌کند).
