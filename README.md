# غلط‌یاب هوشمند چندزبانه (Multilingual Smart Spell Checker)

این پروژه یک سامانه‌ی مبتنی بر وب است که متن ورودی شما را در چهار زبان **فارسی، انگلیسی، عربی و ترکی استانبولی** دریافت کرده، زبان آن را به‌طور خودکار تشخیص می‌دهد و سپس متن را از نظر املایی و نگارشی اصلاح و نرمال‌سازی می‌کند.

## ✨ ویژگی‌ها

-   **تشخیص خودکار زبان**: با استفاده از `langdetect`، زبان متن بدون نیاز به انتخاب دستی شناسایی می‌شود.
-   **نرمال‌سازی و اصلاح تخصصی**:
    -   **فارسی**: اصلاح نیم‌فاصله، یکسان‌سازی حروف و غلط‌یابی با `hazm-normalizer` و `pyspellchecker`.
    -   **عربی**: نرمال‌سازی همزه، حذف اعراب و غلط‌یابی با `PyArabic` و `pyspellchecker`.
    -   **ترکی استانبولی**: غلط‌یابی و پیشنهاد اصلاح با `zemberek-python`.
    -   **انگلیسی**: غلط‌یابی استاندارد با `pyspellchecker`.
-   **رابط کاربری ساده و واکنش‌گرا**: امکان ورود متن، انتخاب زبان (یا تشخیص خودکار) و مشاهده‌ی خروجی اصلاح‌شده در یک تکست‌باکس قابل کپی.
-   **معماری Serverless**: مستقر بر روی Vercel با استفاده از FastAPI و Mangum.

## 🛠️ تکنولوژی‌های استفاده‌شده

-   **Backend**: Python, FastAPI, Mangum
-   **NLP Libraries**: Langdetect, PySpellChecker, PyArabic, Hazm-Normalizer, Zemberek-Python
-   **Frontend**: HTML, CSS, JavaScript (Vanilla)
-   **Deployment**: Vercel

## 🚀 نحوه‌ی اجرا و استقرار

1.  مخزن را کلون کنید یا فایل‌ها را در GitHub خود قرار دهید.
2.  وابستگی‌ها را در فایل `requirements.txt` بررسی کنید.
3.  پروژه را به Vercel متصل کنید (از طریق داشبورد Vercel یا CLI).
4.  Vercel به‌طور خودکار وابستگی‌ها را نصب کرده و برنامه را اجرا می‌کند.

## 📝 نحوه‌ی استفاده

1.  آدرس پروژه را در مرورگر باز کنید.
2.  متن خود را در کادر ورودی بنویسید یا جای‌گذاری کنید.
3.  زبان را انتخاب کنید (پیش‌فرض: تشخیص خودکار).
4.  روی دکمه‌ی «پردازش و اصلاح متن» کلیک کنید.
5.  متن اصلاح‌شده در کادر پایین نمایش داده می‌شود و قابل کپی است.
