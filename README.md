# غلط‌یاب هوشمند چندزبانه (Multilingual Smart Spell Checker)

این پروژه یک وب‌سرویس مبتنی بر FastAPI است که متن شما را در چهار زبان **فارسی، انگلیسی، عربی و ترکی استانبولی** به صورت هوشمند پردازش، نرمال‌سازی و اصلاح می‌کند.

## ✨ ویژگی‌های کلیدی
- **تشخیص و پردازش متن‌های ترکیبی (Mixed-Language)**: برنامه خط به خط متن را بررسی کرده و زبان هر خط را تشخیص می‌دهد. این یعنی می‌توانید در یک متن همزمان فارسی، انگلیسی و عربی بنویسید و تمامی آن‌ها به درستی اصلاح شوند.
- **معماری ضدباگ (Anti-Crash)**: استفاده از بلوک‌های `try-except` برای تمامی کتابخانه‌ها. اگر پردازش یک زبان با خطا مواجه شود (مثلاً به دلیل محدودیت حجم Vercel)، بقیه زبان‌ها بدون مشکل پردازش می‌شوند.
- **نرمال‌سازی تخصصی**:
  - فارسی: اصلاح نیم‌فاصله و یکسان‌سازی حروف با Hazm.
  - عربی: اصلاح همزه و حذف اعراب با PyArabic.
  - انگلیسی و ترکی: غلط‌یابی کلمه‌به‌کلمه با PySpellChecker و Zemberek.

## 🛠️ تکنولوژی‌ها
- **Backend**: Python 3.12, FastAPI, Mangum (برای Serverless)
- **NLP**: PySpellChecker, PyArabic, Hazm-Normalizer, Zemberek-Python
- **Frontend**: HTML5, CSS3, Vanilla JS
- **Hosting**: Vercel

## 🚀 راه‌اندازی در Vercel
1. کدها را در یک مخزن GitHub قرار دهید.
2. در داشبورد Vercel، مخزن را Import کنید.
3. تنظیمات را روی حالت پیش‌فرض (Other) رها کنید و Deploy بزنید.
